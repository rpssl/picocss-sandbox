PICO.CSS peskovnik
namenjeno testiranju PICO.CSS ogrodja 

Pico CSS je lahek, minimalističen CSS ogrodje, namenjeno oblikovanju semantičnega HTML-ja brez potrebe po množici razredov (classes) ali JavaScripta.

Glavne značilnosti

• Semantični pristop: Privzeto lepo in odzivno oblikuje osnovne HTML elemente (naslove, tabele, obrazce, gumbe).
• Minimalno število razredov: Uporablja manj kot 10 razredov (npr. .container, .grid) oziroma ponuja tudi različico brez razredov (class-less).
• Brez odvisnosti in JS: Ne zahteva JavaScripta; samodejno podpira svetli in temni način (prefers-color-scheme) ter ročno preklapljanje z atributom data-theme.
• Prilagodljivost: Ponuja več kot 130 spremenljivk CSS, podporo za SCSS in več barvnih tem.

Uporaba in omejitve

• Za kaj je primeren: Odličen za hitre prototipe, dokumentacijo, pristajalne strani, manjše projekte in interna orodja.
• Omejitve: Ni namenjen zelo kompleksnim aplikacijam po meri ali podrobno določenim dizajnom. Po izdaji različice 1.1 (kot zadnje uradne izdaje) je bil repozitorij arhiviran, obstoječe datoteke in CDN pa ostajajo dostopni (licenca MIT).
Več podrobnosti in dokumentacijo najdete na uradni strani Pico CSS ali v repozitoriju GitHub picocss/pico.
